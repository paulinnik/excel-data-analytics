# Проект: Дашборд по зарплатам в Excel

## Описание проекта

Этот проект был выполнен мной в рамках курса по анализу данных в **Excel**. Основная задача — трансформировать сырые данные о вакансиях в интерактивный аналитический инструмент, который помогает соискателям оценивать рыночную стоимость своих навыков.

Дашборд позволяет пользователям проводить мини-исследование рынка труда, сравнивать зарплаты на разных позициях и понимать, какие навыки ценятся работодателями больше всего.

### Инструменты и методы

В процессе анализа и визуализации были применены следующие инструменты и методы:

- **Диаграммы и графики:** создание динамических визуализаций для наглядного сравнения показателей.
- **Формулы и функции:** использование продвинутых функций для агрегации данных и расчета ключевых метрик.
- **Проверка данных (Data Validation):** обеспечение чистоты и корректности вводимых данных для стабильной работы дашборда.

---

## О наборе данных

Для этого проекта использовался набор данных с реальной информацией о вакансиях в сфере **Data Science** за 2023 год.

Датасет предоставлен в рамках курса по Excel, который заложил фундамент для глубокого анализа данных. Набор данных включает подробные сведения по следующим направлениям:

- Названия должностей (**Job titles**)
- Уровни зарплат (**Salaries**)
- Локации (**Locations**)
- Ключевые навыки (**Skills**)
